# Healthcare Data Analytics

## Project Overview

This project presents an end-to-end analysis of healthcare data to identify patterns and trends in patient demographics, medical conditions, hospital admissions, treatment costs, insurance providers, medications, and test results.

The project demonstrates a practical data analytics workflow using SQL, Python, and Power BI, with the objective of transforming raw healthcare data into meaningful and actionable insights.

---

## Business Problem

Healthcare organizations generate large volumes of patient and hospital data. Analyzing this information can help identify patterns in patient admissions, medical conditions, treatment costs, and patient outcomes.

This project aims to answer questions such as:

- What are the most common medical conditions?
- How are patients distributed across different age groups and genders?
- How do admissions vary over time?
- Which medical conditions are associated with higher billing amounts?
- How does length of hospital stay vary across patient groups?
- What are the major insurance providers represented in the dataset?
- What medications and test results are most common?
- What patterns can be identified from patient and admission data?

---

## Dataset

The project uses a publicly available healthcare dataset obtained from Kaggle.

The dataset contains approximately 55,500 patient records and 15 attributes covering patient demographics, medical conditions, admission information, billing, insurance, medication, and test results.

### Dataset Attributes

- Name
- Age
- Gender
- Blood Type
- Medical Condition
- Date of Admission
- Doctor
- Hospital
- Insurance Provider
- Billing Amount
- Room Number
- Admission Type
- Discharge Date
- Medication
- Test Results

The original dataset is preserved in the `dataset` folder.

## Objectives

- Understand and profile the healthcare dataset.
